# Hybrid RAG System Architecture

## Overview

Hybrid RAG (Retrieval-Augmented Generation) combines dense vector search with sparse BM25 retrieval to deliver high-precision, context-aware answers from a document corpus. This document describes the system's components, data flow, and design decisions.

---

                                                                                                                                                                                                                                      ## Components
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      ### 1. Ingestion Pipeline (`ingestion/`)
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      - **Loader** (`loader.py`): reads PDF, Markdown, and plain-text files.
                                                                                                                                                                                                                                      - **Chunker** (`chunker.py`): splits documents into overlapping chunks with configurable size and stride.
                                                                                                                                                                                                                                      - **Embedder**: encodes chunks with a sentence-transformer model and stores vectors in FAISS.
                                                                                                                                                                                                                                      - **BM25 Indexer**: builds an inverted index over chunk tokens for sparse retrieval.
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      ### 2. Retrieval Layer (`retrieval/`)
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      - **DenseRetriever** (`dense.py`): ANN search over FAISS index; returns top-k by cosine similarity.
                                                                                                                                                                                                                                      - **SparseRetriever** (`sparse.py`): BM25 keyword search; returns top-k by BM25 score.
                                                                                                                                                                                                                                      - **HybridRetriever** (`hybrid.py`): fuses dense and sparse ranked lists using Reciprocal Rank Fusion (RRF).
                                                                                                                                                                                                                                      - **Reranker** (`reranker.py`): cross-encoder model re-scores fused candidates and returns top-n.
                                                                                                                                                                                                                                      - **MetadataFilter** (`filter.py`): pre-filters candidates by source, date, or custom tags before reranking.
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      ### 3. Generation Layer (`generation/`)
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      - **ContextBuilder**: assembles retrieved chunks into a structured prompt.
                                                                                                                                                                                                                                      - **Generator** (`generator.py`): calls the LLM (streaming supported) and returns the answer with citations.
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      ### 4. API Layer (`api/`)
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      - **FastAPI app** with `/query`, `/ingest`, `/health`, and `/metrics` endpoints.
                                                                                                                                                                                                                                      - Pydantic models for request/response validation.
                                                                                                                                                                                                                                      - Prometheus metrics exposed at `/metrics`.
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      ### 5. Monitoring (`monitoring/`)
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      - **HealthCheck** (`health_check.py`): liveness and readiness probes.
                                                                                                                                                                                                                                      - **Metrics collector**: tracks query latency, retrieval hit-rate, and generation token counts.
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      ### 6. Evaluation (`eval/`)
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      - RAGAS-based evaluation of faithfulness, answer relevancy, and context precision.
                                                                                                                                                                                                                                      - Benchmark results stored in `eval/benchmark_results.json`.
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      ---
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      ## Data Flow
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      1. Documents are ingested, chunked, embedded, and indexed (FAISS + BM25).
                                                                                                                                                                                                                                      2. A user query hits the `/query` endpoint.
                                                                                                                                                                                                                                      3. The query is embedded and used for dense ANN search.
                                                                                                                                                                                                                                      4. The same query is tokenised for BM25 sparse search.
                                                                                                                                                                                                                                      5. RRF fuses both ranked lists into a unified candidate set.
                                                                                                                                                                                                                                      6. The cross-encoder reranker re-scores and truncates to top-n.
                                                                                                                                                                                                                                      7. The context builder formats chunks into an LLM prompt.
                                                                                                                                                                                                                                      8. The LLM generator produces an answer with inline citations.
                                                                                                                                                                                                                                      9. The response is returned to the caller.

                                                                                                                                                                                                                                      ## Design Decisions
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      | Decision | Rationale |
                                                                                                                                                                                                                                      |---|---|
                                                                                                                                                                                                                                      | Hybrid retrieval (dense + sparse) | Captures both semantic similarity and keyword precision |
                                                                                                                                                                                                                                      | RRF fusion | Parameter-free, robust across score distributions |
                                                                                                                                                                                                                                      | Cross-encoder reranker | Higher accuracy than bi-encoder for top-n selection |
                                                                                                                                                                                                                                      | FAISS (flat + IVF) | Scales from prototype (flat) to production (IVF) without API change |
                                                                                                                                                                                                                                      | FastAPI | Async support, automatic OpenAPI docs, Pydantic validation |
                                                                                                                                                                                                                                      | RAGAS evaluation | Standard metrics aligned with RAG research community |

                                                                                                                                                                                                                                      ## Configuration
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      All tuneable parameters live in `config/`:
                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                      - `config/ingestion_config.yaml` — chunk size, overlap, embedding model.
                                                                                                                                                                                                                                      - `config/retrieval_config.yaml` — top-k for dense/sparse, RRF k constant, reranker top-n.
                                                                                                                                                                                                                                      - `config/generation_config.yaml` — LLM model, temperature, max tokens.
